# GradeMaster

A Python application designed to calculate student grades and GPA based on the Moroccan educational grading system.

## Overview

GradeMaster helps Moroccan students calculate their subject averages and overall GPA based on the standard Moroccan grading scale (out of 20) and weighted subject coefficients.

## Features

- Calculates overall GPA using grades out of 20 and weighted subject coefficients.
- Automatically determines official academic mentions based on final results.
- Validates input to ensure grades remain strictly within the valid range (0 to 20).
- Simple command-line interface.

## Built With

- Python 3

## How to Run

1. Clone the repository:
git clone https://github.com/ImadOuchine/GradeMaster.git

2. Navigate to the project directory:
cd GradeMaster

3. Run the application:
python main.py
